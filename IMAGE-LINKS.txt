FRERA WEBSITE - IMAGE LINKS
===========================

To replace an image, open the file and location listed below, then replace
the current URL with the new image URL. Keep the quotes around the URL.


CATEGORY CARD IMAGES
--------------------
The category cards display their images through:
  src/components/CategoryCard.jsx

Change the image URL in the matching category object in:
  src/data/siteData.js

OTHER PAGES' HERO BACKGROUND IMAGE
---------------------------------
File:
  src/styles/global.css

The .page-hero style is shared by the About, Contact, Property, Vehicles,
Scrap & Metals, Industrial Products, and Services pages. Replace the URL
marked with the "Inner-page hero background image" comment to change the
background image on all those pages.

  https://images.unsplash.com/photo-1486406146926-c627a92ad1ab?auto=format&fit=crop&w=1800&q=85
